**Prerequisites:**  Node.js
**Prerequisites:**  Python 3.12+


1. **Set Environment Variables**: Create a `.env` file in the root directory and add your Gemini API key:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```
2. **Install Frontend Dependencies**:
   ```bash
   npm install
   ```
3. **Setup and Run the Backend**: Follow the instructions in the backend/README.md to start the Python server.
4. **Run the Frontend**:
   ```bash
   npm run dev
   ```
